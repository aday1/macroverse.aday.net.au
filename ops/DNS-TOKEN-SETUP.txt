Cloudflare DNS automation for Linode hostnames needs a token with:

  Zone - DNS - Edit
  Zone - Zone - Read

Scope: aday.net.au

Create at: https://dash.cloudflare.com/profile/api-tokens

Then set GitHub secret on aday1/aday-net-au (and optionally macroverse.aday.net.au):

  gh secret set CLOUDFLARE_API_TOKEN --repo aday1/aday-net-au

The Pages deploy token (Workers/Pages only) returns HTTP 403 on dns_records API.

Run workflow: aday1/aday-net-au -> Actions -> sync-linode-dns
